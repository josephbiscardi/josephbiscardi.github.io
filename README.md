# Joseph Biscardi – Modern Personal Site

This is a clean, modern, single-page professional portfolio.

## Contents
- `index.html` – Complete self-contained site (CSS embedded)
- `profile.jpg` – Professional headshot

## How to Deploy on GitHub Pages (recommended)

1. In your existing `josephbiscardi.github.io` repository (or a new one):
   - Delete or move the old Jekyll theme files (`_config.yml`, `_layouts`, etc.) if you want a pure static site.
   - Upload `index.html` and `profile.jpg` to the root of the repository.
2. Commit and push. GitHub Pages will serve `index.html` automatically.
3. Your custom domain (`josephbiscardi.com`) should continue working if CNAME is already set.

## Alternative: Quick local preview
Open `index.html` in any browser.

## Customization tips
- Update contact details, LinkedIn, or add a downloadable PDF resume link.
- Add a Projects / Homelab section if you want to showcase specific builds or scripts.
- Colors and fonts are controlled via the CSS variables at the top of the `<style>` block.
